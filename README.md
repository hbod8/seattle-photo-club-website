# Seattle Photo Club Website

This is a hugo website for the Seattle Photo Club. The goals are:

1. Links to existing member websites. Linking to member websites benefits both seattle photo club and the end website as the link moves both up in the google page rank algorithm, meaning googling “seattle photo club” is more likely to give results to member websites and our discord/instagram.
2. Member portfolio pages. Members can request a portfolio page for free and submit a short bio and photos. This is a really big barrier to entry as websites are a prerequisite for many gallery or art show entries. I would be willing to run a request section somewhere in the discord where people could ask for this service. (help-and-questions has consistently noted website help)
3. Information/Knowledge section. The updated list of film developing labs in Seattle updated with information from member testimonials. Furthermore, many technical discord users have made short guides and dont maintain their own webpages and could be invited to post blog post style content here.
